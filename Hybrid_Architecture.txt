campus-ops/
├── client/                               # Frontend UI Layer (HTML5, Tailwind CSS, JS)
│   ├── assets/                           # Global branding, icons, and static assets
│   ├── admin.html                        # Estate Office & Supervisor Console Dashboard
│   ├── facility.html                     # Ground Technician Duty Desk & Field Verification View
│   ├── login.html                        # Unified Authentication Gateway (Supabase Auth Integration)
│   ├── qr-resolver.html                  # Mobile QR Code Location & Equipment Tag Resolver
│   ├── student.html                      # Student Incident Discovery, Notice Board, & Reporting Hub
│   ├── teacher.html                      # Faculty Academic Fast-Track & SLA Endorsement Portal
│   └── ticket.html                       # Live Ticket Audit Timeline, Stepper, & Feedback View
│
├── server/                               # Centralized Backend (Node.js/Express + Supabase JS Client)
│   ├── config/                           
│   │   └── supabaseClient.js             # [Supabase Bridge] Initializes createClient() using SUPABASE_URL and SUPABASE_ANON/SERVICE_KEY.
│   ├── controllers/                      
│   │   ├── authController.js             # [Supabase Auth] Handles server-side session checks and role verification.
│   │   ├── ticketController.js           # [Supabase DB] Fast queries for inserting, updating, and fetching tickets & upvotes.
│   │   └── noticeController.js           # [Supabase DB] Manages retrieval/creation of admin broadcasts and AI telemetry.
│   ├── routes/                           
│   │   └── api.js                        # [API Router] Connects client-side fetch calls to Supabase server actions.
│   └── app.js                            # [Server Entry] Express setup with CORS, body-parsers, and route mounting.
│
├── smart-contracts/                      # Decentralized Core (Used ONLY for Financial Escrow & Tamper-Proof Audits)
│   ├── contracts/                        
│   │   ├── VendorEscrow.sol              # [Solidity] Manages high-value repair funds escrow (e.g., Daikin chiller/lathe POs).
│   │   └── TrustChainAudit.sol           # [Solidity] Stores immutable SHA-256 hash checkpoints for critical safety logs.
│   ├── scripts/                          
│   │   └── deploy.js                     # Hardhat/Foundry deployment scripts for Ethereum testnet.
│   └── test/                             
│       └── escrow.test.js                # Unit tests for secure fund release.
│
├── middleware/                           # Security, Authentication & Hybrid Routing
│   ├── rbac.js                           # [Supabase JWT Verification] Middleware validating user roles (Student, Teacher, Worker, Admin).
│   └── blockchain-bridge.js              # [Web3 Connector] Links Supabase database triggers (e.g., PO approval) to smart contracts.
│
├── .env                                  # Environment variables (SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY, RPC_URL, PRIVATE_KEY)
├── package.json                          # Dependencies (@supabase/supabase-js, express, cors, ethers, dotenv)
└── README.md                             # Project overview and deployment guide
